# 文献资料

这里是论文事实和阅读材料的权威区。目录按材料角色划分：

- [`papers/`](papers/)：论文 PDF 的规范副本；
- [`notes/`](notes/)：一篇论文一份的结构化阅读笔记；
- [`evidence/`](evidence/)：证据表、筛选记录和核验例外；
- [`bibliography/`](bibliography/)：已核验的 BibTeX；
- [`reading-packs/`](reading-packs/)：面向学习路径的精选阅读包，PDF 通过链接引用 `papers/`。

维护时，论文元数据和证据等级以 `evidence/` 为准，引用以 `bibliography/references.bib` 为准，综合性结论回到 [`reviews/`](../reviews/) 查找。

新增论文的最小流程是：先放入待核验区并记录来源，完成标题/作者/版本核验后再规范命名，随后补充证据记录、BibTeX 和阅读笔记（如已全文阅读）。
