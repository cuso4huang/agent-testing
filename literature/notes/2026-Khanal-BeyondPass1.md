# Beyond pass@1 阅读笔记

- 论文：*Beyond pass@1: A Reliability Science Framework for Long-Horizon LLM Agents*
- 年份/版本：2026，arXiv:2603.29231。
- 研究问题：长任务中能力排名是否等价于可靠性排名，以及失败如何随时间累积。
- 方法：在多领域、不同持续时间桶上重复运行 agent，构建可靠性衰减、方差/波动和失控行为指标。
- 主要结论：可靠性衰减依领域而异；长任务中模型能力和可靠性排名会分离；复杂策略会带来新的失控模式。
- 测试启示：必须按任务长度分层报告，保存 meltdown/循环等失败簇，不能只报总体 pass@1。
- 局限：预印本；任务时间代理、基础设施故障和模型版本可能影响外推。
- 开源：全文开放；代码和完整轨迹开放状态需继续核验。
- 证据：全文阅读，benchmark、指标、实验与局限已检查。
