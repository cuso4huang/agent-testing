# MASEval 阅读笔记

- 论文：*MASEval: Extending Multi-Agent Evaluation from Models to Systems*
- 年份/版本：ACL 2026 System Demonstrations；DOI `10.18653/v1/2026.acl-demo.34`。
- 研究问题：如何比较 topology、orchestration、memory 和 error handling，而不是只比较固定 agent setup 下的模型。
- 方法：跨 benchmark、模型和多个开源 multi-agent frameworks 运行统一评测。
- 主要结论：framework 与实现选择会显著改变结果，模型中心 leaderboard 会掩盖系统层差异。
- 局限：框架、模型和任务矩阵有限；快速变化的版本影响复现。
- 开源：系统/论文资源开放，具体版本需随实验记录锁定。
- 证据：全文阅读，设计、实验和结论已检查。
