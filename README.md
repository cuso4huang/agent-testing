# AI 智能体测试论文仓库

这是一个围绕 **AI 智能体（AI Agent）测试与质量保障** 的中文文献调研仓库，重点关注具有规划、工具调用、记忆、环境交互或多智能体协作能力的 Agentic System。

仓库不只是论文文件合集，还整理了系统综述、逐篇阅读笔记、证据表、检索与筛选记录、BibTeX，以及面向研究选题和工程实践的专题报告。当前资料主要覆盖 2020–2026 年文献，重点关注 2023 年以来的研究进展。仓库结构整理截至 **2026-09-21**；具体证据日期以各报告和证据表为准。

## 研究内容

本仓库主要讨论以下问题：

- 智能体测试与传统软件测试、普通 LLM 评测有何不同；
- 如何测试任务完成、规划、推理、工具调用、记忆和多智能体协作；
- 如何评价可靠性、稳定性、安全性、可复现性、成本与延迟；
- 如何发现错误工具调用、循环执行、状态漂移、提示注入、越权和级联失败；
- 如何设计可执行环境、复合 Oracle、重复与扰动测试、故障注入和轨迹诊断；
- 当前领域的研究空白，以及适合论文、毕业设计和工程实践的方向。

一个核心观点是：智能体测试不能只检查最终答案。测试还应覆盖完整执行轨迹、环境终态、外部副作用、权限与策略合规性、重复运行可靠性，以及资源消耗。

## 研究方法与证据规范

本仓库按照可追溯的文献调研流程维护：

- 使用标题、作者、DOI、arXiv ID 等信息去重并核验版本；
- 区分正式发表版本、会议接收稿和预印本；
- 将证据分为“已阅读全文”“仅阅读摘要”“仅核验元数据”和“二手引用待核验”；
- 只有全文证据用于支撑细粒度的方法、实验和局限性分析；
- 在筛选表中记录文献的纳入、排除及原因；
- 不直接横向比较定义不同的 success rate、ASR、cost 或 judge 分数。

详细流程见 [调研规范](docs/research-guidelines.md)，检索过程见 [检索日志](searches/logs/search-log.md)，逐篇证据等级见 [证据表](literature/evidence/evidence-table.csv)。

## 方法分类

仓库中的研究大致归纳为八类：

1. 测试用例与场景自动生成；
2. 可控执行环境与状态型 Oracle；
3. 轨迹级复合 Oracle 与 evaluator 测试；
4. 重复、扰动与回归测试；
5. 安全红队、对抗测试与灰盒模糊测试；
6. 故障注入、混沌测试与恢复能力评价；
7. 失败诊断、根因定位与多智能体归因；
8. 可观测性、重放与持续验证。

这些方法共同服务于 Web/浏览器 Agent、代码 Agent、工具调用 Agent、记忆型 Agent、多智能体系统及具身 Agent。
